# Support

- **Questions and ideas:** GitHub Discussions (once the repository is public).
- **Bugs:** open an issue using the bug template. Include `npx ship-anything doctor --json` output and the
  exact command you ran.
- **Security issues:** never in public issues — see [SECURITY.md](SECURITY.md).
- **Maintainer contact:** to be published with the first public release.

Before filing: run `ship-anything validate` and `ship-anything doctor`, and check
[docs/guides/getting-started.md](docs/guides/getting-started.md).

Support is best-effort by volunteers; there is no guaranteed response time.
